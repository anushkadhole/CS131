The input file was randomly shuffled with shuf. The head command selected
the required number of lines, and wc -l verified each sample size.

Commands used:

F=../A3/downloaded_tweets_extend_nolf.ASCII.CLEAN.tsv
TOTAL=$(wc -l < "$F")
N=$(awk -v n="$TOTAL" 'BEGIN {printf "%d", n/100}')
shuf < "$F" | head -n "$N" > sample_1.txt
wc -l sample_1.txt

For loop used for 1% through 10%:

for x in $(seq 1 10)
do
    N=$(awk -v n="$TOTAL" -v p="$x" 'BEGIN {printf "%d", n*p/100}')
    OUT="sample_${x}.txt"
    shuf < "$F" | head -n "$N" > "$OUT"
    ln -sfn "$OUT" "subsam.$x"
    echo "Percentage: ${x}%"
    echo -n "Expected: "
    echo "$N"
    echo -n "Actual:   "
    wc -l < "$OUT"
done
